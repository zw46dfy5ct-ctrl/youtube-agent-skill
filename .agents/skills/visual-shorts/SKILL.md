Прочитай profiles/cube-physics.md, если пользователь не указал другой профиль. По идее предложи два конкретных действия для первых двух секунд. Выбери одно и объясни, что зритель заметит на экране телефона. Составь таблицу сцен: начало и конец в секундах, действие, камера, английский промпт. Сумма сцен должна давать выбранную длительность. В каждом промпте сохраняй объект, материал, свет и направление движения предыдущей сцены. Укажи точку склейки для повтора. Выдай отдельно название и описание для YouTube, подпись и тематические хештеги для TikTok, переведи текст на русский. Образцы в examples/cube-pilots.md.
При анализе экспорта удержания уточни единицу оси. Запускай python skills/yt-retention/retention.py файл.csv --axis seconds --opening 3 --json. Для процентов укажи --axis percent --duration и фактическую длительность. Привяжи интервал падения к сцене и предложи одну проверяемую правку. Сравнивай на одной платформе ролики близкой длины через одинаковое время после публикации.
